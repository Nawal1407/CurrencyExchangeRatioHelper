DESIGN DOCUMENT
Project: Currency Exchange Calculator
Version: 1.0

1. System Architecture
The system is a fully client‑side web application consisting of:

HTML: Structure and semantic layout

CSS: PoE‑style theme and layout control

JavaScript: Ratio logic, event handling, persistence, modal behavior

No backend or external libraries are used.

4. Interaction Design
4.1 Ratio Adjustment
Clicking ▲ increases value by increment.

Clicking ▼ decreases value by increment.

Changing WANT resets HAVE to 1.

Changing HAVE resets WANT to 1.

4.2 Modal Behavior
Gear icon opens modal.

Clicking outside modal closes it.

Modal does not affect layout.

4.3 Persistence
All inputs save on change.

All inputs restore on page load.

5. Calculation Logic
5.1 Whole Number Conversion
Convert decimals to whole numbers by scaling based on decimal precision.

5.2 Trade Computation
Minimum = 1 block

Half = floor(maxBlocks / 2)

Maximum = maxBlocks

5.3 Remainder
remainder = items - (offerWhole * blocks)

5.4 Fallback Logic
If maxBlocks < 1:

Show error box

Show last valid ratio

Show last valid results

7. Risks & Mitigations
Risk	Mitigation
User enters invalid numbers	Input validation + fallback
Modal blocks interaction	Click‑outside close
Layout breaks on small screens	Fixed widths + flexbox
Browser arrows appear	CSS removal rules

Headers match styling and alignment
